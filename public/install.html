STANDALONE ASSISTANT

Get the app on your phone

There is one app for Android phones and a Home Screen web app for iPhone. Both need an internet connection for answers. It gives Georgia legal information, not legal advice.

Android

Download Android app (APK, version 1.7.4)

  1. Tap the button above and open the downloaded file.
  2. If Android asks, allow your browser or Files app to install unknown apps, then tap Install.
  3. Already have an earlier version? Installing this one updates it in place.

This app is downloaded directly from the project's GitHub release page, not from Google Play. Release details.

iPhone and iPad

There is no App Store app. You can add the web app to your Home Screen:

  1. Open this site in Safari.
  2. Tap the Share button (square with an arrow).
  3. Scroll down and tap Add to Home Screen.
  4. If you see Open as Web App, leave it on.
  5. Tap Add. The icon appears on your Home Screen.

Any other phone or computer

Use it in your web browser: open the web app. Not every device or browser is guaranteed to support installing it.
